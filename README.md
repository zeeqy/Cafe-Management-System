# BijiKopi Cafe: Cafe Management System

A console application that helps a cafe owner order coffee beans, take payment, track total sales and print receipts.

Built for **CSC186 (Object-Oriented Programming)** at UiTM.

## What it demonstrates

- **Inheritance and polymorphism**: `CoffeeBean` is the base class, with `Decaffein` and `ExtraCaff` subclasses that price differently
- **Encapsulation**: sales logic is kept in its own `Sales` class
- **File I/O**: running sales totals are saved to `totalsales.txt`

## Tech stack

Java (developed in BlueJ)

## Running

```bash
cd src
javac *.java
java Main
```
